# Telegram Mini App - B2B Wholesale Terminal

## Location

The Telegram Mini App is located in the `telegram-mini-app/` directory.

## Quick Start

```bash
cd telegram-mini-app
npm install
npm run dev
```

## Build

```bash
cd telegram-mini-app
npm run build
```

## Documentation

See `telegram-mini-app/README.md` for full documentation.

## Features

- ⚡ High-speed wholesale ordering interface
- 📱 Mobile-first design optimized for Telegram Web App
- 🌙 Dark mode optimized for sunlight readability
- 🔢 Custom numpad for quantity entry (no native keyboard)
- 📊 Real-time stock indicators with urgency alerts
- 💾 Cart persistence across sessions
- ✨ Smooth animations and transitions

## Tech Stack

- React 19 + Vite
- TypeScript
- Tailwind CSS 4
- Zustand (state management)
- Lucide React (icons)
